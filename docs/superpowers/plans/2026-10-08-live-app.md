# Live App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make hosted mode (Clerk + Supabase) ready for real users, add a real federal "open for comment" feed, and deploy the web build publicly.

**Architecture:** One new SQL migration wraps `lookaware_snapshot` / `lookaware_command` (existing rename-and-wrap pattern) for claims sync and account deletion. Client changes gate demo-only content on `isDemo`. Federal rules come straight from the keyless Federal Register API through a pure, tested mapping module and a TanStack Query hook; no server or table.

**Tech Stack:** Expo SDK 57, Expo Router, TanStack Query, Zod, Clerk (`@clerk/expo`), Supabase, PGlite (DB tests), Jest.

**Spec:** `docs/superpowers/specs/2026-10-08-live-app-design.md`

## Global Constraints

- Never put service-role keys, Clerk secret keys, `ANTHROPIC_API_KEY` or `OPENSTATES_API_KEY` in client code or `EXPO_PUBLIC_` variables.
- The fictional seed is never pushed to a live project.
- Live mode must never show "fictional", "sample" or "(simulated)" wording for real data; demo mode keeps it.
- External links open only after a leaving-the-app confirmation, and only `https` on `federalregister.gov` / `regulations.gov`.
- Strict TypeScript, no `any`; StyleSheet/inline-style design system already in use; match surrounding code.

## Review Focus

- Clerk token without `email_verified` / `name` claims (misconfigured dashboard): stored values must stay unchanged, not reset to false → DB test in Task 1.
- `name` claim empty or one character: profile keeps the placeholder, no constraint violation → DB test in Task 1.
- Deleting an account that owns petitions other people signed: those petitions leave public view, other people's signatures are untouched → DB test in Task 1.
- Federal Register returns an item with a non-https or off-domain `comment_url`, or missing fields: item dropped or link falls back to `html_url` → unit test in Task 4.
- Federal fetch fails (offline demo): Home and Explore render normally with no federal section → handled by the rail returning `null` on error/empty (Task 5).

- [ ] Write the migration:

```sql
begin;

-- Signed Clerk claims are the source of truth for email verification and the starting name.
-- Returns true when it changed something, so the snapshot can reload once.
create function private.sync_claims() returns boolean language plpgsql security definer set search_path='' as $$
declare uid uuid:=private.actor(); claims jsonb:=auth.jwt(); nm text:=left(trim(coalesce(claims->>'name','')),100);
 changed boolean:=false; n integer;
begin
 if uid is null then return false; end if;
 if claims ? 'email_verified' then
  update private.principals set email_verified=coalesce((claims->>'email_verified')::boolean,false)
   where profile_id=uid and email_verified is distinct from coalesce((claims->>'email_verified')::boolean,false);
  get diagnostics n=row_count; changed:=n>0;
 end if;
 if length(nm)>=2 then
  update public.profiles set name=nm where id=uid and name='Community member';
  get diagnostics n=row_count; changed:=changed or n>0;
 end if;
 return changed;
end $$;
revoke all on function private.sync_claims() from public,anon,authenticated;

alter function public.lookaware_snapshot() rename to lookaware_snapshot_v7;
revoke all on function public.lookaware_snapshot_v7() from public,anon,authenticated;
create function public.lookaware_snapshot() returns jsonb language plpgsql security definer set search_path='' as $$
declare result jsonb:=public.lookaware_snapshot_v7();
begin
 -- The first load provisions the account; a changed claim needs one more read to show.
 if private.sync_claims() then result:=public.lookaware_snapshot_v7(); end if;
 return result;
end $$;
revoke all on function public.lookaware_snapshot() from public,anon,authenticated;
grant execute on function public.lookaware_snapshot() to anon,authenticated;

alter function public.lookaware_command(jsonb) rename to lookaware_command_v10;
revoke all on function public.lookaware_command_v10(jsonb) from public,anon,authenticated;
create function public.lookaware_command(command jsonb) returns text language plpgsql security definer set search_path='' as $$
declare uid uuid:=private.actor();
begin
 if command->>'type'<>'delete_account' then return public.lookaware_command_v10(command); end if;
 if uid is null then raise exception 'Sign in before making changes.'; end if;
 -- Personal records go. Receipts and referral credit cascade with signatures.
 delete from public.signatures where user_id=uid;
 delete from private.signature_referrals where referrer_id=uid;
 delete from private.ripple_codes where user_id=uid;
 delete from private.signature_receipts where user_id=uid;
 delete from private.eligibility_requests where user_id=uid;
 delete from private.civic_lookups where profile_id=uid;
 delete from public.user_interests where user_id=uid;
 delete from public.community_members where user_id=uid;
 delete from public.petition_saves where user_id=uid;
 delete from public.petition_drafts where user_id=uid;
 delete from public.petition_volunteers where user_id=uid;
 delete from public.petition_collaborators where user_id=uid;
 delete from public.post_reports where user_id=uid;
 delete from public.reports where user_id=uid;
 delete from public.user_badges where user_id=uid;
 delete from public.notifications where user_id=uid;
 -- Their petitions leave public view; what they wrote in public stays, unattributed.
 update public.petitions set status='archived',updated_at=now() where owner_id=uid and status<>'archived';
 update public.profiles set name='Deleted account',city='',bio='',onboarded=false where id=uid;
 delete from private.principals where profile_id=uid;
 return null;
end $$;
revoke all on function public.lookaware_command(jsonb) from public,anon;
grant execute on function public.lookaware_command(jsonb) to authenticated;

commit;
```

- [ ] Run `npm run test:db` → passes. Commit.
